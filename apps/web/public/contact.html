문의

계산 결과가 이상해 보이거나, 규제가 바뀌었는데 반영되지 않은 것을 발견했거나, 있었으면 하는 기능이 있다면 알려 주세요.

문의 남기는 곳

문의는 GitHub 이슈로 받습니다. GitHub 계정으로 로그인한 뒤 "New issue"를 눌러 내용을 적어 주세요. 남긴 문의와 답변은 공개되므로 실명, 연락처, 정확한 소득·자산, 계좌 정보는 적지 마세요. 계산 오류를 알려 줄 때도 "연소득 약 6천만원"처럼 대략의 값이면 충분합니다.

보통 며칠 안에 확인합니다. 규제 수치와 관련된 제보는 공식 발표와 대조한 뒤 계산기, 정책 요약, 가이드 글에 함께 반영합니다.

빨리 확인할 수 있게 적어 주세요

  • 계산 오류: 어느 화면(메인 계산기, 디딤돌·신생아특례·주담대 한도·DSR 계산기 중 어디)에서, 대략 어떤 값을 넣었을 때, 결과가 얼마로 나왔고 왜 이상하다고 느꼈는지. 은행이나 기금 포털에서 받은 숫자와 비교했다면 그 출처도 적어 주세요. 화면의 "결과 공유" 링크를 붙여 주면 같은 조건을 그대로 재현할 수 있습니다.
  • 규제 변경 제보: 바뀐 내용과 시행일, 근거가 된 보도자료나 공고 링크.
  • 화면 문제: 기기와 브라우저(예: 아이폰 사파리, 갤럭시 크롬), 어떤 동작을 했을 때 생기는지.
  • 기능 제안: 어떤 상황에서 무엇을 확인하고 싶었는지. 예를 들어 "청약 당첨 후 잔금 대출을 계산하고 싶다"처럼 구체적일수록 좋습니다.

답하기 어려운 문의

"이 집을 사도 될까요", "어느 은행 대출이 유리한가요" 같은 개별 상담에는 답하지 않습니다. 이 사이트는 공개된 규제 기준으로 범위를 계산해 보여 주는 도구이고, 대출 중개나 금융·세무 자문을 하지 않습니다. 실제 한도와 금리는 은행, 주택도시기금, 한국주택금융공사에 문의해 주세요.

자주 받는 질문은 자주 묻는 질문에 정리해 두었습니다. 문의를 남기기 전에 먼저 확인해 보세요.
